# Live Currency Tracker

A simple Python application that fetches live exchange rates from a REST API and handles connection errors.

## Features
- **Real-Time Data:** Fetches up-to-date currency exchange rates.
- **Error Handling:** Built-in `try-except` blocks for network issues.
- **JSON Parsing:** Converts API responses into Python data structures.

## Requirements & Setup
```bash
pip install requests
python ExchangeRate.py
